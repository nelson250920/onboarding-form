How to map:

1. Load LOA.pdf.
2. Select the PDF page.
3. Select the field.
4. Click Start Mapping.
5. Draw a rectangle exactly over the location where the value should appear.
6. Release the mouse.
7. The mapping is automatically saved.

You can map the same field many times.

Example:
Name → Page 1
Name → Page 2
Name → Page 4
