How to map:

1. Choose the 9-page PDF.

2. Go to the required PDF page using Previous / Next.

3. Select a field.

4. Select Text or Checkbox/Radio.

5. Click Start Mapping.

6. Draw a rectangle exactly over the location where that information belongs.

7. Click Save Mapping.

8. Repeat for every field on all 9 pages.

Important: The mapper automatically records the page number and the position relative to that page.
