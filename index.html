How to map:

1. Load the 9-page PDF.
2. Select the page.
3. Select a field.
4. Select Text or Checkbox.
5. Click Start Mapping.
6. Draw the rectangle on the PDF.
7. Click Save Mapping.

IMPORTANT: The same field can be mapped multiple times.

Example:
Page 6 → Date
Page 7 → Date
Both mappings will remain saved.

You can also map Date twice on the same page.
